# 차량 화면 기준

모두 집으로는 센터 디스플레이에서 장소와 방문 순서를 고르는 앱이다
기본 화면에서 주소·좌표·일곱 구간의 시간을 직접 입력하게 하지 않는다
집과 하차·볼일 장소를 선택하면 현재 차량 위치에서 경로를 조회한다

## 선택 흐름

- 함께 귀가는 동승자 1~2명과 집 앞 하차 장소, 볼일 0~1건 선택
- 가는김에는 집과 픽업·장보기 최대 2건 선택
- 함께 귀가의 하차 장소는 안전한 정차와 집 앞 직접 하차 여부를 큰 확인 버튼으로 확인
- 체류시간과 더 걸려도 괜찮은 시간을 큰 프리셋 버튼으로 선택
- 가는김에는 최대 두 방문 순서, 함께 귀가는 최대 여섯 순서의 사람별 도착과 추가시간 비교
- 함께 귀가의 비교는 한 번에 최대 세 계획을 표시하고 나머지는 큰 전환 버튼으로 확인
- 선택한 순서를 한 번 확인하고 차량 내비로 전달
- 정차한 뒤 하차·볼일 완료를 확인하고 마지막에 집 도착 기록

비교·확인 화면의 시간에는 교통 제외 기준을 숫자 바로 위에 표시한다
가는김에는 출발 후 차량 내비에서 확인한 다음 장소와 집까지 남은 주행시간을 표시한다
체류·도보시간은 별도이며 안내 변경이나 조회 실패 시 이전 시간을 현재 시간으로 유지하지 않는다

함께 귀가는 진행 화면에 계획상 다음 정차와 완료 개수를 크게 표시하고, 현재 내비 반영 상태를 따로 보여준다
세 정차를 두 경유지씩 나눠 안내하므로 확정·진행 화면에 첫 정차 완료 후 다음 순서를 반영한다는 설명을 표시한다
현재 안내에 다음 순서가 확인되지 않으면 반영 대기를 표시하고 실제 완료 여부와 내비 재시도를 구분한다
현재 길안내가 해당 단계의 앞 경유지 1~2곳만 제외한 순서와 정확히 맞으면 실제 하차·볼일 완료를 확인하는 큰 확인창을 사용한다
대상 장소와 종류, 실제 내비 안내를 함께 표시하고 두 곳은 모두 마쳤을 때 일괄 확인한다
사용자가 확인한 정차만 완료로 기록하며 확인을 취소하면 완료 개수를 유지한다

장소를 선택하지 않았거나 경로 응답이 없으면 예시 장소·기본 예상시간으로 차량 계획을 만들지 않는다
가는김에의 마감과 보행시간 같은 세부 조건은 입력 제한이 해제된 상태의 상세 화면에서 설정한다
함께 귀가의 기본 입력은 장소·인원·체류·추가시간·필수 하차 확인으로 구성한다

받은 볼일은 차량에서 다시 입력하지 않고 한 건씩 큰 검토창에서 확인한다
기존 볼일과 새 제안의 장소·체류·도보·준비·완료 마감을 비교하고 승인한다
제안에 체류 12분처럼 프리셋 외의 값이 있거나 도보·마감이 포함되면 입력 화면에도 그 값을 표시한다
가는김에 입력 카드에는 해당 체류·편도 도보시간과 마감 날짜·시각을 28sp 이상으로 표시한다
확정 화면에서는 도착 시각과 수령·장보기 완료 시각을 구분하고, 마감이 있으면 도로망 기준 여유시간을 표시한다
출발 직전 마감이 맞지 않으면 비교 화면에서 다른 순서나 조건을 선택한다
이전 날짜·시간대의 마감을 정리할 때는 장소를 유지하고 이전 마감·준비 확인을 지운다는 큰 확인창을 사용한다
수신·검토와 경로 출발은 구분하며, 주행 제한이나 화면 이탈이 발생하면 열린 검토창을 닫는다

휴대폰 연결은 차량에서 QR을 보여주고 동승자가 연결 주소를 확인하는 흐름으로 제공한다
차량에서 함께 공유할 볼일의 장소명을 표시하고 한 건만 선택하며 집·하차 장소·전체 계획은 보내지 않는다
주행 제한이나 화면 이탈 시 연결창을 닫고 연결 토큰은 저장하지 않는다
차량 앱이 화면에 열린 동안에는 제한 여부와 별개로 받은 제안을 수신함에 저장하며 자동으로 검토창을 열지 않는다
휴대폰의 서버 접수와 차량의 수신함 보관, 운전자의 계획 반영은 각각 구분한다

## 크기와 정보량

| 항목 | 기준 |
| --- | --- |
| 화면 제목 | 40sp |
| 목적지와 본문 | 28~32sp |
| 주요 시간과 다음 목적지 | 48~52sp |
| 보조 정보·버튼 문구 | 28sp 이상 |
| 조작 영역 | 80dp 이상 |
| 주요 실행 버튼 | 96dp 이상 |
| 장소·음성 선택창 | 넓은 차량 영역, 고정 닫기·확인 버튼 |

- 중요한 오류는 상단에 표시하고 스크롤 아래로 숨기지 않음
- 앱 영역이 1320dp보다 좁거나 글자 배율이 커지면 제목과 상단 조작을 나눠 배치
- 상단 조작은 공간이 부족하면 다음 줄로 배치하고 글자 크기를 줄이지 않음
- 픽업·장보기 카드 영역이 1000dp보다 좁거나 글자 배율이 커지면 세로로 배치
- 체류·추가시간 숫자와 단위는 큰 버튼 안에서 함께 표시
- 한 화면에서 해야 할 주요 행동은 하단 버튼 하나로 표시
- 함께 귀가의 하단 행동은 경로 비교 → 선택한 순서 확인 → 출발 → 다음 정차 완료 → 집 도착 순서로 전환
- 긴 장소명은 줄 수를 제한하고 선택창에서 전체 이름·주소 확인
- 터치 영역과 글자는 실제 AVD 앱 영역에서 확인하고 전체 디스플레이 크기로만 판단하지 않음
- 운전석 거리에서의 물리적 글자 크기는 실제 차량 디스플레이에서 별도 확인

## 주행 제한

차량 기어를 추측해 잠그지 않고 현재 디스플레이의 `CarUxRestrictions`를 따른다
연결 전·오류·주행 제한 중에는 계획 편집을 잠근다

- 상세 입력, 장소 목록, 제안 승인, 완료 처리, 내비 전송, 음성 입력 차단
- 열린 선택창을 닫고 현재 계획 보존
- 제한 중 앱 내부 화면은 스크롤·입력 없이 최대 세 항목만 표시
- 플랫폼이 내려준 문자열 길이·항목 수·메뉴 깊이 제한 반영
- 일반 Activity에는 `distractionOptimized`를 선언하지 않고 OS의 주행 차단 유지
- 실제 길 안내는 선택한 경로를 받은 차량 내비가 담당

큰 글자만으로 주행 중 사용 승인을 대신할 수 없다
주행 중 앱 자체를 계속 표시하는 배포는 Pleos의 앱 유형·심사 조건을 확인한 뒤 판단한다

## 음성

가는김에의 말로 선택은 debug 빌드에 기본으로 포함한다
release의 음성 입력은 실차 권한·주행 정책을 검증한 환경에서 `enableVehicleVoice=true`로 활성화한다
`enableVehicleVoice=false`로 빌드하면 터치 선택만 제공한다

- 말로 선택 버튼을 누를 때만 차량 온디바이스 인식 시작
- 마이크 권한은 버튼을 누를 때 요청하고 승인 뒤 전경·차량 입력 허용 상태를 다시 확인
- 권한 승인 후 전경 복귀를 최대 1초 기다리며 화면을 떠난 뒤 늦게 녹음을 시작하지 않음
- 앱이 16kHz·16bit·mono 녹음을 소유하고 PCM을 SDK에 전달하며 SDK의 마이크 요청은 사용하지 않음
- ‘장도 보고 갈래’, ‘픽업 빼줘’, ‘추가 20분’, ‘수령 준비됐어’처럼 한 가지 요청 처리
- 자유 주소나 복합 문장은 임의로 해석하지 않고 지원 범위 안내
- 인식한 명령은 큰 확인창에 표시하고 적용을 눌러 계획에 반영
- 입력 종료와 최종 결과를 구분하고, 입력 종료 뒤에는 최대 3초 동안 최종 문장을 기다리며 확인 중으로 표시
- 부분 인식 문장만으로 계획을 바꾸지 않고 초기화 이후 인식 결과 대기는 15초 안에서 제한
- 화면이 일시 중지되거나 입력 제한이 생기면 중단 요청
- SDK 입력 종료 시 녹음 중단을 요청하고, 모든 종료·취소 경로에서 녹음 코루틴을 기다린 뒤 리스너·SDK 해제
- 앱 녹음의 정지 상태와 리소스 해제를 확인한 뒤 재요청을 허용하며 확인 실패 시 차단
- 종료를 확인하지 못하면 차량 입력 화면에 터치로 이어 선택하라는 안내 표시
- 이전 요청의 결과가 새 확인창에 나타나지 않도록 요청 세대 확인
- 음성과 인식 문장은 저장하거나 로그로 남기지 않음

인식은 대상 차량의 음성 서비스 응답으로, 녹음 중단은 앱이 소유한 입력의 정지·해제 결과로 확인한다
